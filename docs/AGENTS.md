# Documentation Agent Rules

This folder contains active v4 protocol docs.

- Keep docs aligned with active `contracts/v4/` source and current deployment
  docs.
- Mark v3 and retired incident-stack content as historical only.
- Do not claim a feature is deployed unless current deployment docs prove it.
- Do not claim jackpot, mining, arena, or old cron behavior is active.
- Do not invent addresses, roles, ABIs, or event signatures.
- Generated active v4 artifacts are the ABI source of truth.
- If uncertain, write "unknown, verify before use" rather than guessing.
